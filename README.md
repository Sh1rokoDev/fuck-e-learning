# fuck-e-learning 刷课脚本

一个用于学习通、优学院的油猴脚本。安装后进入课程学习页，右上角会出现控制面板，点击「开始刷课」即可自动处理视频任务点。

## 功能

- 自动识别当前是学习通还是优学院
- 视频自动播放，可静音
- 自动选择课程允许的最高倍速；不能倍速时自动按 1x 播放
- 视频被暂停时自动恢复
- 视频播放完成后自动进入下一个课时
- 已完成课时自动跳过
- 按课时显示运行日志和当前进度
- 面板可拖动、可收起，位置会自动记住
- 刷新或重新进入页面后可以继续上次的运行
- 学习通支持自动答题（需要配置多模态模型）

优学院暂不支持自动答题，面板中的「自动答题」「自动暂存」「跳过已作答」会固定关闭、置灰，并在开关左侧显示「不支持」。

## 安装

1. 在浏览器扩展商店搜索并安装 **Tampermonkey**（油猴）
2. 打开 Tampermonkey 管理面板，点击「添加新脚本」
3. 打开 `fuck-e-learning.user.js`，全选复制全部内容
4. 粘贴到 Tampermonkey 编辑器里，保存
5. 打开课程学习页面，右上角会出现控制面板

支持的页面：

- 学习通：`mooc1.chaoxing.com` 的课程学习页
- 优学院：`ua.ulearning.cn` 的课程学习页

## 使用

1. 进入课程学习页面，等待右上角出现控制面板
2. 点击「开始刷课」
3. 脚本会从当前页面开始，依次处理后面的课时
4. 需要暂停时点击「停止」，当前视频会立即暂停
5. 面板可以按住空白处拖动；点击右上角箭头可收起，点击圆形按钮可重新展开

## 设置说明

面板中的运行设置和「高级设置」会保存在油猴里，学习通与优学院共用同一份设置。在一个平台修改后，另一个平台也会保持相同设置。

| 设置 | 说明 |
| --- | --- |
| 静音播放 | 视频静音播放，学习时长照常记录 |
| 最高倍速 | 自动尝试课程允许的最高倍速，不支持时回到 1x |
| 自动答题 | 仅学习通可用，调用多模态模型自动作答 |
| 自动暂存 | 仅学习通可用，作答后自动点击「暂时保存」 |
| 跳过已作答 | 仅学习通可用，已有答案的题目不再作答 |
| 高级设置 | 配置题型和模型接口，两个平台都可以正常打开 |

功能是否支持只显示在运行设置面板中：不支持的功能会强制关闭、置灰，并在开关左侧显示「不支持」，不会改变已保存的设置。

学习通使用自动答题前，需要在「高级设置」中填写：

- **Base URL**：例如 `https://api.openai.com/v1`
- **API Key**：你的模型接口密钥
- **模型**：必须是支持图片输入的多模态模型，例如 `gpt-4o`、`qwen-vl-max`、`glm-4v`

填写后可以点「测试连通性」检查，再保存。

## 注意事项

- 学习通答题完成后不会自动提交试卷，请进入答题页面人工复核后手动点击「提交」
- 优学院不支持自动答题，练习/答题页面会跳过，需要自己手动完成
- 已结束或已过期的课程可以继续播放，但平台不会保存学习记录
- 视频内弹题、验证码、人脸识别需要手动处理
- 脚本不会处理考试、直播等特殊页面

## 常见问题

**面板没有出现？**

确认 Tampermonkey 已安装并启用，然后刷新页面。脚本只在学习通课程学习页和优学院课程学习页生效。

**视频没有倍速？**

课程或账号没有开放倍速时，脚本会保持 1x 播放，不会强制加速。

**进度没有保存？**

如果课程已经结束或过期，平台本身就不会保存新的学习记录，这不是脚本的问题。

**学习通答题没有自动提交？**

这是刻意设计的，避免误提交。答案会自动点选并暂存，最终提交需要你手动完成。
